SESSIONS DU DASHBOARD DANS NEON POSTGRESQL

La configuration est automatique :
- la même variable DATABASE_URL est utilisée ;
- la table dashboard_sessions est créée au démarrage ;
- les sessions expirées sont nettoyées automatiquement ;
- la durée du cookie reste de 8 heures.

Variables facultatives :
SESSION_DATABASE_POOL_MAX=3
SESSION_PRUNE_INTERVAL_MS=900000

Après déploiement, le log attendu est :
✅ Sessions du dashboard stockées dans Neon PostgreSQL.

L'avertissement MemoryStore ne doit plus apparaître.
