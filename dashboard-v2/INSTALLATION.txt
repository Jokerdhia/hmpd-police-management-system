INSTALLATION HMPD V6

1. Conserve ton fichier .env / tes Environment Variables Render.
2. Vérifie dashboard-v2/ENV-A-AJOUTER.txt.
3. Dans PowerShell :
   npm install
   npm run verify
   npm start
4. Pour enregistrer/recharger les slash commands si nécessaire :
   node deploy-commands.js

Sur Render, la commande de démarrage reste : npm start

Le dashboard V6 utilise un cache-busting automatique dans les URLs CSS/JS ; après un nouveau déploiement, un simple rechargement doit suffire dans la majorité des cas.
