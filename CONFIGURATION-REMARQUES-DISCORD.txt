CONFIGURATION DU SALON REMARQUES DISCORD

Dans Render > ton service > Environment, ajoute :

ATTENDANCE_REMARK_CHANNEL_ID=TON_ID_DE_SALON

Important :
1. Active le mode développeur dans Discord.
2. Clic droit sur le salon « remarques » > Copier l’identifiant du salon.
3. Colle uniquement le nombre, sans # ni espace.
4. Le bot doit avoir dans ce salon : Voir le salon, Envoyer des messages, Intégrer des liens et Mentionner les membres.
5. Après avoir ajouté/modifié la variable dans Render, redéploie ou redémarre le service.

Cette version bloque désormais la fin forcée si le salon n’est pas configuré, et affiche une erreur claire si Discord refuse l’envoi.
